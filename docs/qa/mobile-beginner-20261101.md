# 휴대폰에서 처음 써 보는 ASBC 확인

시간 날 때 Android는 Chrome, iPhone은 Safari로 [ASBC](https://asbc.app/)를 열어 주세요. 오늘 바로 할 필요는 없습니다. 한 기기에서 10분 정도 해 보고 나머지는 나중에 해도 됩니다.

아래는 통과해야 하는 시험이 아닙니다. 다음에 누를 곳을 모르겠으면 그 자체가 개선할 점입니다. 설명을 찾아 헤매지 말고 “여기서 뭘 눌러야 하는지 모르겠다”와 화면 한 장만 남겨 주세요. 버튼 이름을 미리 외우지 않아도 됩니다.

## 먼저 아무 도움 없이 해 보기

처음 온 사람처럼 로그인하지 않은 새 비공개 탭에서 시작하세요. 기존 로그인 탭은 그대로 두면 됩니다. 첫 화면에서 “내 수호성을 키울 때 무엇부터 찍어야 할까?”를 해결해 보세요. 아래 정답 확인 부분은 먼저 읽지 말고, 눈에 보이는 곳 중 맞을 것 같은 것을 눌러 보세요.

1. 수호성 빌드를 찾아 보세요. 잘못 들어갔다면 휴대폰의 뒤로 가기로 돌아와도 됩니다. 직업을 고르는 위치나 첫 행동을 찾기 어려웠는지 기록해 주세요.
2. 아직 캐릭터를 연결하지 않고 데바니온이나 스킬을 바꿀 수 있는지 살펴보세요. 로그인이 반드시 필요하다고 느껴졌는지도 알려 주세요.
3. 연결할 때는 유럽 EU·마족·Ludra의 GreenOrc를 찾아 보세요. 예전 Hadala의 LeekGril은 현재 Ludra의 미쿠이므로, 궁성을 확인할 때는 미쿠를 사용합니다. 다른 검색 결과를 눌렀다가 다시 고를 수 있는지도 봐 주세요.

확인할 점: Steam 로그인과 게임 캐릭터 연결이 서로 다른 기능임을 알 수 있어야 합니다. 연결하지 않아도 입력한 총량으로 계획을 볼 수 있어야 합니다. 조회 실패가 나오면 빈 화면이나 무조건 0으로 바뀌지 않고 다음 행동을 안내해야 합니다.

## 포인트를 잘못 입력한 사람처럼 해 보기

테스트는 사이트 안에서만 합니다. 게임에서 실제 스킬이나 데바니온을 초기화할 필요는 없습니다.

1. 데바니온 총량 칸의 숫자를 전부 지웠다가 114를 입력하고, 다시 370으로 바꿔 보세요. 114와 370은 입력 동작을 보기 위한 예시이며 현재 캐릭터의 실제 총량이라는 뜻은 아닙니다.
2. 키보드가 열린 채로 아래 설명과 적용 버튼을 볼 수 있는지, 닫으면 원래 보던 곳을 계속 볼 수 있는지 확인해 주세요. 숫자 하나를 고치려다 다른 칸이 바뀌지는 않는지도 봐 주세요.
3. 게임 화면을 볼 수 있다면 실제 남은 스킬·스티그마·데바니온 포인트를 각각 적어 보세요. 사용량이 확인되지 않은 항목은 추측해서 0을 넣지 말고, 사이트의 이유와 재확인 안내를 읽어 보세요.
4. “값만 바꾸기”와 “추천 배분 적용하기”의 차이를 설명 없이 구분할 수 있는지 봐 주세요. 적용했다면 직전 배분으로 돌아오는 방법도 찾아 보세요.

확인할 점: 빈칸에서 입력이 막히거나 숫자가 엉뚱하게 붙지 않아야 합니다. 총량을 바꾼 것만으로 직접 찍어 둔 배분을 지우면 안 됩니다. 사용량을 알 때만 사용량과 직접 입력한 남은 양을 합산합니다. 조회가 불완전하면 이유를 표시하고 입력한 남은 양을 보존해야 합니다.

## 손가락으로 데바니온과 특화 고르기

1. 공격력을 찾아 보고, 표시된 노드 하나를 눌러 보세요. 노드 설명과 추가 비용을 찾을 수 있는지 봐 주세요. 바로 찍힌 것으로 착각했는지도 알려 주세요.
2. 다른 보드를 눌렀다가 돌아오세요. 작은 노드를 잘못 눌러도 다시 고를 수 있는지, 보드 이름과 노드를 함께 보기 불편한지 확인해 주세요.
3. 스킬 하나를 올리고 특화 하나를 선택해 보세요. 현재 선택한 특화와 추천하는 특화를 구분할 수 있는지, 설명이 잘리거나 손가락으로 가려지는지 봐 주세요.
4. 가로로 돌렸다가 다시 세로로 돌려 보세요. 화면 전체를 좌우로 밀어야 글을 읽을 수 있다면 알려 주세요.

확인할 점: 노드를 선택하고 경로를 추가하는 단계가 구분돼야 합니다. 사용할 수 없는 특화에는 조건이 보여야 하며, 계획의 스킬 레벨·장비 보너스·최종 레벨을 혼동하지 않아야 합니다.

## 매크로를 처음 만드는 사람처럼 보기

45레벨 PvE 수호성에서 매크로와 키 배치 부분을 찾아 보세요. 스킬을 어떤 세로줄에 놓는지, 매크로에는 어떤 키를 넣는지, 정신력 회복용 기본 공격을 따로 누르는지 화면만 보고 말할 수 있는지 확인해 주세요. 반복 공격에 도발·보호기·돌진을 함께 넣어야 한다고 느껴지는 부분이 있으면 알려 주세요.

확인할 점: 공개 가이드의 기본 반복 예시라는 출처가 보이고, 예시 키를 내 키 설정과 구분할 수 있어야 합니다. 실제 게임 효율이 검증됐다는 뜻으로 읽히면 안 됩니다. PvP나 레벨링으로 바꿨을 때 이 PvE 예시가 그대로 추천으로 남아 있지 않아야 합니다.

## 저장하고 잠깐 다른 일을 했다가 돌아오기

1. 비공개 테스트 탭 안에서만 “휴대폰 확인용”이라는 이름으로 보관해 보세요. 공개 글을 발행할 필요는 없습니다.
2. 메인으로 갔다가 돌아오고, 새로고침도 해 보세요. 같은 탭에서 저장한 수치와 선택이 유지되는지 봐 주세요.
3. 다른 앱을 잠깐 열었다 돌아와 보세요. 처음 화면으로 날아가거나 입력 중인 내용을 잃는지 확인해 주세요.
4. 수정한 배분을 공유하는 링크를 만들 수 있다면 메시지를 보내지 말고 휴대폰 메모장에 붙여 넣어 보세요. 그 링크를 다른 비공개 탭에서 열어 같은 내용을 읽을 수 있는지 확인해 주세요.

확인할 점: 비공개 탭을 모두 닫으면 임시 저장은 없어질 수 있습니다. “이 기기 보관함”은 이름 붙인 보관본이며 자동 기기 동기화 대상이 아닙니다. 로그인 계정의 현재 계획 동기화와 구분돼야 합니다. 공유받은 화면을 연 것만으로 내 현재 계획이 바뀌면 안 됩니다.

## 여유가 있으면 두 기기와 다른 도구 확인

실제 계정의 현재 계획은 먼저 이름을 붙여 보관하고 입력값도 메모해 주세요. 같은 Steam 계정으로 두 기기에 로그인한 뒤 한쪽에서 작은 값을 바꾸고 다른 쪽으로 돌아가 보세요. 동기화 상태가 완료되는지 확인하고 원래 값으로 복원합니다. 휴대폰을 비행기 모드로 바꾼 상태에서 숫자를 하나 수정하고 다시 연결했을 때도 입력이 사라지거나 오래된 값으로 돌아오지 않는지 봐 주세요.

지도에서는 지역 변경 → 히든 큐브 표시 → 한 위치 완료 표시 → 새로고침을 해 보세요. 실제 수집 기록과 섞이지 않도록 사이트 계정에서 로그아웃한 비공개 테스트 탭을 사용합니다. 비공개 탭도 로그인하면 계정 기록과 동기화될 수 있습니다. 거래소에서는 아스바타 5,254키나 두 개와 사포 400키나 한 개를 넣어 보세요. 이 재료의 제작 원가는 10,908키나입니다. 세금·추가 비용·제작 결과 수량을 바꿨을 때 왜 판매가가 달라졌는지 설명을 이해할 수 있는지 확인해 주세요.

## 알려 주실 내용

안드로이드인지 아이폰인지와 사용한 브라우저, 하려던 일, 실제로 누른 것, 예상과 달랐던 화면을 알려 주시면 됩니다. 화면 한 장과 “여기서 다음을 모르겠다”만 있어도 좋습니다. 계정 비밀번호나 로그인 코드는 보내지 마세요.

기록 예시: “아이폰 Safari / 데바 포인트 바꾸려 했음 / 숫자 지우고 370 입력 / 키보드가 버튼을 가려서 적용됐는지 모르겠음.”

실물 휴대폰 확인 상태: 사용자 확인 대기. PC의 모바일 크기 화면 검증과 별도로 기록합니다.

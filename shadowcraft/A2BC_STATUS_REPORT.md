## 공식 원본 위치 미리보기 — 2026-10-18

Verteron·Altgard의 공식 Global Steam 빌드 25926599에서 채집 후보 5,425곳과 이동 후보 122곳을 추출했다. 지도에서 **실험 위치 보기**를 눌러 종류·이름 검색, 후보 선택과 확대 이동을 사용할 수 있다. 자료는 버튼을 누를 때 불러오며 기본 지도에는 표시하지 않는다. 화면은 최대 400개, 선택 목록은 200개로 제한하고 초과 안내를 표시한다.

**위치 정확도는 미검증이다.** 월드 좌표 ÷100을 8192 UI 평면에 배치하는 가설을 적용했다. [Aion2Data의 제작 설명](https://aion2data.com/map/morheim?layer=monoliths)도 같은 방법을 설명하지만 다른 지도·빌드의 설명이며 독립 검증을 대신하지 않는다. 외부 마커 데이터는 복사하지 않았다. 후보 수는 실제 동시 출현 수가 아니며, 보스·NPC 위치나 수집 완료 기록은 이번 미리보기에 포함하지 않았다.

생성기는 원본 파일 SHA-256, 객체·스폰 ID와 XYZ를 보존한다. 분류는 명시적 `GatherSource`/`TeleportArtifact` 값만 사용한다. 두 지도 모두 이름 누락·범위 밖 좌표는 0개였고, 월드 투영 검증 상태는 `false`다. 원본 영문 문자열이 다른 표와 달리 직접 키를 사용하는 점을 확인해 연결했다.

## 지도 탐색 기능 추가 — 2026-10-18

공식 지도 지역명 154개를 현재 지도에서 검색하고 선택 위치로 바로 이동할 수 있다. 선택하면 지도가 열리며 4배 확대·위치 강조를 적용한다. 이동 후 선택 위치로 복귀하거나 선택을 해제할 수 있고, 지도를 바꾸면 검색과 선택이 초기화된다. 지역명 검색은 영문 원본을 사용한다.

프런트엔드 23개 테스트 묶음, 타입 검사, 린트, 빌드와 6개 지도 브라우저 회귀를 통과했다. 390px 모바일 검색·이동, 이미지 실패/재시도, 기존 저장 데이터 유지도 확인했다. 보스·NPC·수집물의 자동 위치 표시는 여전히 미완료이며 이 기능과 구분한다.

## 후속 지도 원본 검증 — 2026-10-18

공식 클라이언트의 UI 타일 설정·배치 컴포넌트·실제 머티리얼 텍스처를 교차 검사하는 도구를 추가했다. 6개 지도 중 5개, 총 164개 타일은 중앙 정렬 격자와 일치했다. `World_D_Starter`는 해당 가정과 배치가 달라 검증 실패로 남겼다. 이 지도는 현재 지역명 게시 대상 4개에 포함되지 않아 기존 게시 데이터를 변경하지 않았다.

이는 **지도 UI 배치 확인**이다. 월드 스폰 좌표의 변환이나 보스·채집물 위치 검증 완료를 의미하지 않는다. 공개 지도 지역 경계와 공식 서브존 경계의 직접 비교도 일치를 확립하지 못했다. 서로 다른 영역 구분·버전일 수 있어 이 결과만으로 변환식이 틀렸다고 단정하지 않는다. 외부 마커를 서비스 데이터로 가져오지 않았다.

검증: 운영 도구 전체 테스트 **110개 통과**, `git diff --check` 통과. 이번 변경에는 사용자 기능 코드가 없어 프런트엔드·백엔드 빌드와 배포는 반복하지 않았다.

새 파일: `operations/audit-map-tiles.py`, `operations/test_map_tiles.py`, `operations/map-tile-audit.json`. 감사 결과에는 원본 SHA-256과 지도별 성공/실패를 기록했다. 사용자 기능·운영 배포는 그대로이며, 아래 전체 완료 판정도 바뀌지 않는다.

## 3. 사용 방법과 핵심 동작

1. **공개 빌드 → 회원가입/로그인**. 블로그 관리자 계정과 별개이며 회원 아이디가 작성자로 공개된다.
2. 원하는 직업의 플래너를 편집하고 **공개 빌드 → 현재 플래너 배분 게시하기**로 게시한다.
3. 내 글 상세에서 **내 게시물 수정 → 저장된 내 배분 불러오기 → 교체 배분 미리보기 → 게시물 수정 저장**으로 배분도 갱신한다. 제목/설명만 바꾸려면 배분을 불러오지 않고 저장한다.
4. **내 게시물만**으로 찾거나 **추천 많은 순**으로 살펴본다. 추천은 계정당 글 하나에 한 번이며 취소할 수 있다.
5. 댓글은 로그인 후 작성하며 본인 댓글만 삭제한다. 관리자에게는 별도 관리 권한이 있다.

배분 불러오기는 로컬 원본을 수정하지 않는다. 캐릭터 프로필·검색 기록·장비 이름·개인 메모는 공유 배분에서 제외한다. 제목·설명·댓글에 직접 입력한 내용은 공개된다. 저장된 배분이 없거나 손상됐으면 기존 게시물을 유지하고 오류를 표시한다. 다른 창에서 먼저 수정됐으면 충돌로 거절한다.

## 5. 실패한 테스트 또는 미확인 사항

최종 로컬 테스트에 남은 실패는 없다. 운영에서 실제로 수행한 검사와 격리 환경에서 수행한 검사는 배포 기록에 구분한다.

- **랭커 상위 10명 분석:** 조사한 공식 글로벌 랭킹 응답이 비어 있고 시즌이 없었다. 다른 공개 사이트의 표본 순위를 전체 서버 공식 순위로 바꾸어 표시하지 않았다. 스킬 특화 선택은 확인한 공식 캐릭터 API에 없다. 근거: `operations/ranker-source-audit.json`.
- **자동 지도 마커:** 지형 타일과 지역명 위치는 연결했으나 월드 좌표→지형 이미지 변환을 독립 기준점으로 검증하지 못했다. 지역명이 같은 구역에 들어오는 것만으로 보스/NPC 위치가 정확하다고 볼 수 없다. 근거: `operations/map-coordinate-audit.json`, `operations/runtime-map-schema-audit.json`.
- **모든 외부 데이터 수집:** 공식 공개 원본 일부와 기존 허용 범위 자료만 확보했다. Grimvane 키 미확보, 제공자 접근 제한/수집 조건이 있는 자료까지 수집 완료라고 표시하지 않는다. 근거: `operations/source-acquisition-report.json`.

## 6. 리스크와 운영 상태

- 회원 비밀번호 찾기/이메일 복구는 아직 없다. 로그인 세션은 별도로 발급·해제하며 브라우저 탭 저장을 사용한다.
- 캐릭터 API·타이머 원본의 가용성과 관측 신선도에 의존한다. 타이머의 빈 값을 임의 주기로 채우지 않는다.
- 기기 저장은 브라우저 데이터 삭제 시 사라질 수 있다. 보관할 개인 계획은 JSON으로 내보내는 기능을 제공한다.
- 일부 프런트엔드 번들의 500 kB 초과 및 빌드 플러그인 시간 경고가 남아 있다. 이번 검사에서 빌드 실패는 없었다.

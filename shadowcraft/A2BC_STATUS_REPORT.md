# a2bc 구현·검증 보고서

기준: 2026-10-16. 제품명: **aion2(Steam) build craft**.

**전체 완료 판정: 보류.** 기존 블로그 이식과 아래 증거가 있는 기능은 운영 중이지만, 사용자가 추가 요청한 사이트 전체 기능과 공식 데이터 전면 전환까지 완료한 상태는 아니다. 이 문서는 완료 선언을 대신하지 않는다.

최신 구현: 공식 클라이언트 제작 기본 확률 미리보기. 운영 검증 결과는 아래 최종 검증 기록을 따른다.

- 9,308개 아이템, 280개 플레이어 스킬, 1,098개 제작법을 공식 Global Steam 클라이언트에서 연결했다.
- 제작법 622개에 숙련도 차이별 기본 예상 확률 입력·전체 표를 제공한다. 476개에는 연결된 확률표가 없어 명시적으로 표시한다. 원본 환산 단위는 사용자 관측 57개 지점과 정수 부분이 일치하며, 소수점 둘째 자리까지 **약** 값으로 표시한다.
- 190개 계승 제작법의 후보 아이템 380개를 연결한다. 일반 재료 수량과 계승 후보를 섞지 않는다.
- 공식 지형 6개 지역·189타일, 지도 내부 지역명 154개를 표시한다. 패키지 스키마 오류는 런타임 구조 대조로 해결했다. 게임 월드 좌표에서 지도 이미지로의 변환은 아직 별개 미확인 사항이다.
- 퀘스트 1,429개, 보상 연결 1,321건, 직업별 보상 112행, 던전 733개와 펫 209개를 조회한다.
- 스킬 기본 수치 592개 치환과 성장 그룹 484개 연결을 검증했다. 최종 전투 수치 적용 규칙 전체를 검증한 것은 아니다.
- 기존 빌드 저장·복구·공유, 관리자 공개 빌드, 장비 비교·OCR, 직접 재료 계산, 공지 갱신을 보존한다.

**남은 한계:** 서버 보정·제작 비용·연속 제작 확률, 최종 전투 계산, 공식 NPC/수집 월드 좌표 투영, 공식 실시간 랭킹·서버 혼잡도 경로. 관측된 값만으로 이 항목들을 완료 처리하지 않는다. 공개 빌드 0건은 기능 오류가 아니라 게시물이 없는 상태다.

## 5. 완료를 막는 구체적 근거

1. **지도 좌표 변환:** 지도 패키지 스키마 오류는 해결했고 12개 패키지·1,267개 객체의 엄격한 해독을 통과했다. 남은 것은 게임 월드 좌표와 이미지 좌표의 대조다. Ishalgen은 타일 원점도 다르므로 하나의 추정 변환을 모든 지역에 적용하지 않는다. 근거: `operations/runtime-map-schema-audit.json`.
2. **제작 확률·비용:** Gap:Int8 / Rate:UInt32 필드는 런타임 정의로 확인했다. 사용자의 57개 관측 지점과 환산값이 일치하며 기본 예상치 화면을 구현했다. 기본 등급 환산은 공식 CraftMastery 구간과 관측으로 연결했다. 캐릭터 보정·연속 제작 확률·실제 수수료는 아직 미확인이다. 근거: `operations/runtime-crafting-schema-audit.json`, `operations/crafting-observation-audit.json`.
3. **전투 데이터:** 학습 비용과 일부 보드 효과의 일치는 전체 스킬 효과·배율·스탯 연산의 정확성을 증명하지 않는다. 기존 정상 작동 카탈로그를 불완전한 공식 필드로 덮어쓰지 않았다.
4. **실시간 서비스:** 현재 사용하는 공식 EU 서버 목록 API에서 46개 레코드의 필드는 raceId/serverId/serverName/serverShortName이다. 이를 온라인 상태로 간주하지 않는다. 참고 사이트의 [서버 상태](https://aion2.gaming.tools/server-status)와 [티어 분석](https://aion2.gaming.tools/tier-list)은 별도의 실시간 상태·리더보드 표본 기능이다. 해당 사이트의 수집 데이터를 복제하지 않았으며, 우리 쪽 공식 수집·검증 체계는 아직 없다.

위 문제는 새로운 허가를 받는 것만으로 해결되지 않는다. 이미 승인된 범위에서 조사했지만, 정확성의 근거가 없는 항목까지 완료라고 표시할 수 없다. 후속 구현도 남아 있으므로 전체 프로젝트가 끝났다고 판단하지 않는다.

## 6. 리스크와 다음 작업

기존 저장 데이터와 원본 파일을 보존했다. 클라이언트 빌드 스냅샷과 운영 서버는 다를 수 있고, 일부 이름은 미확인이다. 프런트엔드 청크 크기 경고가 남아 있다.

다음 완료 관문은 지도 월드 좌표 대조, 제작 보정/비용·전투 수치 적용 규칙 검증, 공식 실시간 상태/랭킹 수집 경로 확보다. 확보 후 각각 독립적인 테스트와 운영 수용 검사를 거쳐야 하며, 조회 목록 추가만으로 이를 대체하지 않는다.

## 7. 지도 후속 진단 — 2026-10-16

현재 매핑의 상속 구조를 직접 조회한 결과, MaterialInstanceDynamic은 총 21개 슬롯(0~20)인데 지도 해독 로그에서는 24번을 64회 요청한다. StaticMeshComponent 136번은 `Unknown` 타입으로 121회 요청된다. AionWorldSettings의 요청 인덱스는 존재하므로, 앞서 확인한 64바이트 미소비 문제는 인덱스 존재 여부만으로 판별할 수 없다.

이를 재현하는 `audit-mapping-coverage.py`와 연구 도구용 조회 패치를 추가했다. 입력 해시·상속 구조·오류 건수는 `operations/mapping-coverage-audit.json`에 기록했다. 실제 입력은 예상대로 종료 코드 1로 거부되며, Python 테스트 57개가 통과했다. 정확한 대체 필드 의미는 아직 확인되지 않았고, 서비스 좌표나 마커를 변경하지 않았다. 전체 완료 판정은 계속 보류한다.

연구 도구 자체 테스트 54개도 통과했다. 이번에는 서비스 런타임 변경이 없어 프런트엔드 빌드·브라우저 검사는 재실행하지 않았다.

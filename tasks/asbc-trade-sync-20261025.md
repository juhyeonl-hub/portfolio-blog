## 구현
- 거래 장부·저장한 제작 계획을 같은 Steam 계정에 자동 동기화. 서로 다른 품목/계획의 동시 수정은 병합, 같은 품목의 충돌은 덮어쓰지 않고 양쪽 잔량·최근 거래와 백업을 보여 주어 선택.
- JSON 백업 다운로드, 유효성 검사와 복원 미리보기, 복원 전 기록 백업. 로그인 전 기록은 명시적으로 확인한 뒤 가져오기. 계정 간 데이터 및 미저장 제작 입력 분리.
- 계산기에서 실제 구매 확인 후 장부에 기록. 구매 상한 계산의 예상 가격은 실매입가로 자동 기록하지 않으며 실제 가격 입력 필요. 이중 확인 방지.
- 제작 계획 최대 20개 저장·비교. 전체 재료 가치에 따른 순이익과 보유 재료를 반영한 추가 구매 자금을 구분. 모바일 하단 저장 버튼.
- 개인정보 설명과 한국어·영어·일본어·핀란드어 UI 반영. 실제 게임 수수료·성공률·레시피를 추정하지 않음.
